# AI Form Assistant

An AI-powered inclusive form assistant that helps users fill forms easily through voice interaction and chatbot guidance.

## Features
- Upload PDF/Image forms
- AI-based question extraction
- Voice-enabled chatbot interaction
- Speech-to-text user response
- Text-to-speech chatbot questions
- Multilingual support (English, Tamil, Hindi)
- Automatic PDF form filling
- Download completed PDF
- Flutter mobile integration with FastAPI backend

## Technologies Used
### Frontend
- Flutter
- Dart

### Backend
- FastAPI
- Python

### AI / Processing
- OCR
- Speech Recognition
- Text-to-Speech

## Project Workflow
1. User uploads a form
2. Questions are extracted automatically
3. Chatbot asks questions
4. User answers via text or voice
5. AI validates answers
6. Form is auto-filled
7. Completed PDF is generated and downloaded

## Run the Project

### Backend
```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Flutter App
```bash
flutter run
```
